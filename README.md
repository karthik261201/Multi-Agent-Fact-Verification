# Multi-Agent Fact Verification

## Project Title

A Multi-Agent Framework for Explainable and Evidence-Grounded Fact Verification

## Overview

This project develops an intelligent multi-agent system capable of verifying user-provided claims using evidence dynamically retrieved from external sources.

The system consists of:

- Claim Analysis Agent
- Evidence Retrieval Agent
- Verification Agent
- Orchestrator

The system retrieves external evidence, evaluates the claim against the retrieved evidence, and produces an explainable verification result.
